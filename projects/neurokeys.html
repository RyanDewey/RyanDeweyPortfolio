NeuroKeys

Brain-Computer Interface Piano · CruX UCLA · 1st Place, California Neurotech Conference

Overview

NeuroKeys is a brain-computer interface piano developed by Ryan Dewey and the CruX UCLA Neurotech Competition team — and the project that won 1st place at the annual California Neurotech Conference. The system lets users select and play piano keys using only biosignals — no hands required.

The project combines two signal modalities: EEG (electroencephalography) for determining which key the user intends to play, and EMG (electromyography) for triggering when a note fires. Together they create an intuitive, low-latency interface for controlling the instrument purely through brain activity and voluntary muscle movement.

Technical Approach

Key Selection — SSVEP + FBTRCA

Each piano key is associated with a flickering visual stimulus at a distinct frequency. When the user focuses on a key, their visual cortex generates steady-state visual evoked potentials (SSVEP) — brainwave oscillations locked to that stimulus frequency. The FBTRCA (Filter Bank Task-Related Component Analysis) algorithm processes multi-channel EEG data across multiple frequency bands to accurately decode which key the user is attending to.

Note Triggering — EMG + SVM

A Support Vector Machine (SVM) classifier trained on surface EMG signals detects voluntary muscle contractions. When the user makes a deliberate movement, the classifier fires the selected note. This cleanly separates selection intent from play intent, giving the user precise control over note timing without accidental triggers.
