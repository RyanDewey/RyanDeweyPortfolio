Silverfish

Go-based Web Crawler & Scraper

Overview

Silverfish is a concurrent web crawler and scraper written in Go, purpose-built for aggregating structured data from restaurant websites. Given a list of seed URLs, it crawls each site, extracts relevant business information, and exports everything to a clean CSV file ready for sales and marketing workflows.

The tool was built to solve a real need: manually researching restaurant websites is slow and inconsistent. Silverfish automates that process at scale, leveraging Go's goroutine model to crawl multiple sites concurrently without blocking.

Technical Approach

Concurrent Crawling

Silverfish uses Go's goroutine and channel model to crawl multiple restaurant websites in parallel. A worker pool limits concurrency to avoid overwhelming targets, while a shared visited map with mutex locking prevents duplicate requests across goroutines.

Data Extraction & Export

HTML is parsed using Go's standard library to locate and extract relevant fields — contact info, hours, menu links, and more. Results are streamed into a structured CSV using Go's encoding/csv package, making the output immediately usable in spreadsheet or CRM tools.
